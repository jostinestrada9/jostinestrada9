### 🚀 Proyectos Destacados

#### 📦 Sistema de Control Logístico & Inventario (Desktop/Mobile)
> **Problema:** Control manual de inventario, conciliación de créditos y carga de rutas de distribución.
> **Solución:** Aplicación desarrollada en Python y Flet para automatizar el registro de ventas diarias, stock y conciliaciones en tiempo real.
- 🔹 **Stack:** Python, Flet, Pandas, SQLite.
- 🔹 **Impacto:** Optimización del tiempo de procesamiento diario de datos y eliminación de discrepancias en la entrega de rutas.

#### 🛒 Plataforma Web & Panel Comercial para Negocios Locales
> **Problema:** Falta de presencia digital y herramientas simples de catalogación para comercios locales.
> **Solución:** Aplicación web desarrollada en Django con panel de administración dinámico para la gestión de productos, categorías e información del negocio.
- 🌐 **Demo en vivo:** [https://webjostin.pythonanywhere.com/](https://webjostin.pythonanywhere.com/)
- 🔹 **Stack:** Python 3.13, Django, Tailwind CSS, Pillow, PythonAnywhere.
- 🔹 **Lo que incluye:** Panel de administración a la medida (`Negocios`, `Categorías`, `Productos`), procesamiento dinámico de imágenes e interfaz responsive.
